Antes de la semana 1

Terminal y Python

Mis primeros ejercicios: organizar y respaldar archivos desde la terminal, y escribir los primeros programas en Python.

  • Riwi Estructura de carpetas para una empresa ficticia (administración, clientes, proyectos, reportes y respaldos) y un portal de clientes en HTML y CSS.
  • ProyectoCoders Práctica de terminal: carpetas de código, configuración, documentación y copias de respaldo.
  • ProyectoTerminal Notas y pendientes organizados en carpetas con comandos.
  • salchipapa-solucion Una receta convertida en algoritmo de Python, con preguntas por consola y condicionales.
  • por Mi primer programa en Python (pide el nombre y saluda) y mi primera página HTML.

Semana 1

Rueda Libre con HTML y CSS

El primer sitio de Rueda Libre, un negocio ficticio de alquiler de bicicletas y recorridos guiados en Medellín: portada, tarifas, formulario de reservas y página de confirmación.

  • semana1Riwi Cuatro páginas HTML, hoja de estilos propia, fotos de las bicicletas y una bitácora donde anoté qué hace cada tecnología: HTML como esqueleto, CSS como diseño y JavaScript como interacción.

Tecnologías: HTML, CSS.

Semana 2

Accesibilidad, Grid, Flexbox y Bootstrap

El mismo sitio de Rueda Libre, reconstruido en tres días: primero con CSS propio, luego comparado con Bootstrap 5.3 y al final migrado con la marca personalizada.

  • Día 1 HTML semántico y accesible: idioma de la página, jerarquía de títulos, formularios con fieldset y textos alternativos. Diseño adaptable con Grid y Flexbox.
  • Día 2 Prueba comparativa de CSS propio contra Bootstrap, y tres conflictos entre ambos que diagnostiqué con las herramientas del navegador.
  • Día 3 Migración completa a Bootstrap 5.3 con colores y tipografía de la marca, un botón con buen contraste, carrusel de promociones y modal de políticas en el formulario.

Tecnologías: HTML, CSS, Bootstrap 5.3. Ver el repositorio.

Semana 3

Rueda Nocturna con Tailwind CSS

Una campaña nueva para Rueda Libre: rodadas de noche, de jueves a sábado. Con ella pasé de Bootstrap a Tailwind CSS 4.

  • Día 1 Introducción a Tailwind: landing de la campaña y un kit de componentes con botones, tarjeta de ruta, alertas y campos de formulario.
  • Día 2 Tema propio con @theme (fuentes y colores de marca) y un botón reutilizable con @apply.
  • Día 3 Landing completa con rutas, planes y un formulario de inscripción que valida nombre, correo y celular en el navegador.

Tecnologías: HTML, Tailwind CSS 4. La bitácora incluye una comparativa entre Bootstrap y Tailwind. Ver el repositorio.

Aparte

Formulario con base de datos

Un formulario web que guarda en una base de datos el nombre, el celular y el correo de quien lo llena, y luego muestra una página de confirmación.

  • formulario_con_bases_de_datos El formulario en HTML y CSS envía los datos por POST a un script en PHP que los inserta en MySQL.

Tecnologías: HTML, CSS, PHP, MySQL.

Aparte

Ejercicios con IA

Tres ejercicios de las sesiones de inteligencia artificial de la semana 2.

  • IA_SEMANA2 Un algoritmo que ordena tres números de menor a mayor; el borrador descargable de la actividad «Tres cupos, ocho estudiantes», con dos consultas a la IA comparadas; y Merca Fácil, una página hecha con una herramienta de IA para armar la lista de mercado, fijar un presupuesto, comparar supermercados y ver recetas sugeridas.

Tecnologías: Next.js, React, TypeScript.
