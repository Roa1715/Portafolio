# Portafolio

Página personal con los proyectos que he hecho en Riwi, organizados como una subida: de los primeros ejercicios de terminal y Python a una landing con Tailwind CSS.

## Contenido

- `index.html`: la página.
- `styles.css`: estilos (sin frameworks ni dependencias).

## Cómo verla

Abre `index.html` en el navegador. Para publicarla, activa GitHub Pages en **Settings → Pages**, con la rama `main` y la carpeta raíz.
